# AI-assisted restoration (2026)

## Original PFE work (2020)

The original 2020 PFE was a pair project by **Yassine DAOUJI** and **Mohammed
AZZOUZ**. Yassine led the overall project and did the data collection, ML,
backend, and report work; Mohammed built the original React/Spring report
application. The project also produced the model-training notebooks, the first
Flask prediction service, the presentation, and the datasets in `Data/` and
`Documents/`.

The original notebooks and report are preserved as academic work:

- `MachineLearning/NewsClassifier.ipynb`
- `MachineLearning/NewsPolarityClassifier.ipynb`
- `Documents/RapportPFE_BusinessNewsAnalysis.pdf`
- `Documents/Rapport_PFE_Business_News_Analysis.docx`
- `Documents/Présentation PFE.pptx`

Those files were not generated by the AI agent.

## 2026 restoration and enhancements

The 2026 project was reviewed and enhanced by **Yassine DAOUJI in collaboration
with the OpenCode AI coding agent, using the DeepSeek V4.1 Flash model**.

Yassine DAOUJI defined the goals and scope, reviewed the technical decisions,
and ran/validated the resulting stack. The agent implemented and documented the
restoration work listed below.

### What was added or updated with AI assistance

| Area | AI-assisted work |
|---|---|
| Prediction service | Repaired the broken artifact paths, restored the Flask service, added `/health`, `/analyze`, `/analyze/batch`, and the legacy integer endpoints |
| Business model | Added a reproducible Random Forest training script with metrics |
| Polarity models | Integrated FinBERT, an offline TF-IDF fallback, a local HuggingFace path, and the optional legacy ktrain path |
| Data layer | Added the normalized MongoDB schema, deduplication, indexes, fixture generation, seeding, date shifting, and evaluation scripts |
| Demo data | Generated 120 news fixtures and 40 tweet fixtures from the original labeled dataset |
| Streamlit UI | Built the new dashboard: overview, sentiment charts, ticker explorer, live analyzer, raw data view |
| Legacy UI | Restored the original React + Spring app from git history, fixed its build/runtime issues, seeded users/roles/societies, and adapted its data schema |
| Collectors | Reworked the NewsAPI/Twitter entrypoints to use the prediction service; added the Twitter fixture path and API v2 migration skeleton |
| Infrastructure | Added Dockerfiles, Docker Compose, Make targets, environment configuration, and the local MongoDB fallback |
| Tests | Added service, preprocessing/schema, and end-to-end smoke tests |
| Security | Removed hardcoded credentials from current files, added `.env` handling, and documented secret rotation/history cleanup |
| Documentation | Added architecture, demo, training, legacy-stack, Twitter migration, and security guides, plus screenshots |

### What was not changed by the agent

- The original PFE report and presentation.
- The original training notebooks.
- The original datasets.
- The original 2020 application code, including the React/Spring app built by
  Mohammed AZZOUZ, which remains recoverable from git history and is documented
  in `docs/LEGACY_STACK.md`.
