# Labs

Older and generic experiments kept for reference. Nothing in this folder is
required by the main news-analysis pipeline.

- `kafka-twitter-elasticsearch/` — a Twitter producer and Elasticsearch
  consumer lab imported from `kafka-with-twitter-and-elasticsearch`.
- `elasticsearch-python/` — a MovieLens CSV → Elasticsearch bulk-indexing lab
  imported from `elasticsearch-with-python`.

Each folder has its own README with the original purpose and run notes. See
`docs/PROVENANCE.md` for source revisions.
