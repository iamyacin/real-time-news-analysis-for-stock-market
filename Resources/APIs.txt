# External APIs used by the original PFE

The 2020 project used:

- NewsAPI — https://newsapi.org/
- Twitter/X API — https://developer.x.com/
- Yahoo Finance options endpoint — https://query1.finance.yahoo.com/

Credentials are no longer stored in this repository. Put your own keys in
`.env`; see `.env.example` and `docs/SECURITY.md`.

The old hardcoded values were removed during the 2026 restoration. Rotate any
key that may still be active.
